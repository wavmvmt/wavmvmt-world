How this alpha works

1. Arrive at the virtual Center. 2. Start a music-production quest. 3. Build a real eight-step pattern. 4. Hear or watch one bar play. 5. Unlock skill nodes in your Mind Palace.

This is a standalone browser prototype. Progress is saved only in your browser. Audio is off until you switch it on. No login, tracking, email capture, outside APIs or money transactions.

Prototype notes

Built to test a game loop.

What actually works

One-choice or skip onboarding; center navigation; an editable eight-step sequencer; optional local synthesized audio; photography composition and virtual wayfinding challenges; a connected Mind Palace graph; and a local Player Passport with reset and JSON export.

What does not exist yet

No walkable 3D environment in this prototype, multiplayer, live guide AI, shared economy, careers engine, real-world financial forecasts or cross-device profile sync. These require separate builds and verification.

Where this fits

Separate from the existing WAVMVMT World 3D repo and WAVMVMT World Game design repo. Intended for review first, with future integration into the public WAVMVMT ecosystem only after approval.

Your local data

Stored only in this browser using localStorage (when available). The versioned JSON export contains your selected onboarding path, pattern and completed local-demo quests. Old alpha progress migrates without losing completed quests. No personal profile is requested.
